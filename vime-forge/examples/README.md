# Examples

- [cann_bench_evaluator](cann_bench_evaluator/README.md) 将 AscendC 算子提交至 CANN-Bench，以编译、精度和性能结果计算奖励。
- [cann_bench_single_turn](cann_bench_single_turn/README.md) 使用单轮 GRPO 训练模型生成 AscendC 算子代码。
- [geo3k_vlm](geo3k_vlm/README.md) 介绍 Geo3K 图文几何推理任务的数据准备，以及单轮和多轮训练的启动方式。
- [geo3k_vlm_multi_turn](geo3k_vlm_multi_turn) 提供 Geo3K 多轮推理的交互环境、轨迹生成器和训练脚本。
- [swe_agent_rl](swe_agent_rl/README.md) SWE-Gym的 AgenticRL 训练并基于独立沙箱验证，按测试结果计算奖励。
- [terminal_agent_rl](terminal_agent_rl/README.md) 运行 [TMax](https://arxiv.org/abs/2606.23321) 任务的 AgenticRL 训练。
